# Typography & Iconography

## Type pairing
Display/headings: a monumental serif (Cinzel, Marcellus, or Cormorant), self-hosted, reserved for hero type and the logo lockup. Body copy: a humanist sans (Inter or Public Sans), self-hosted, for sustained reading.

## Type scale
A modular scale (ratio 1.25) anchored at 16px, consistent across Portfolio and Blog.

## Iconography
A custom line-icon set inspired by hieroglyphic silhouettes, used only as small decorative accents. Primary navigational icons remain conventional glyphs.

## Multilingual and RTL typography
Body and display type choices are verified for adequate Arabic script support (or a documented Arabic-specific fallback pairing) before Arabic ships as a locale, since the primary display serif is a Latin-script face and may not cover Arabic glyphs. This check is a Definition of Done item for the milestone that actually ships Arabic content, not assumed by the RTL layout groundwork in M11 alone.
